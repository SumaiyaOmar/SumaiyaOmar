## 🚀 Featured Projects
### 🧠 Second Opinion — AI Data Truth Engine
An AI-assisted analytics tool that audits business claims against CSV data, investigates hidden segment patterns, and produces evidence-based verdicts.

- **Claim auditing:** Checks supported numerical claims using deterministic Python calculations.
- **Segment analysis:** Investigates trends, composition shifts, and cases where aggregate results hide opposing segment-level patterns.
- **Stress testing:** Evaluates conclusions against predefined checks and reports limitations or inconclusive results.
- **Evidence transparency:** Provides computational receipts so users can inspect the calculations and supporting evidence.

**Tech Stack:** Python · Streamlit · pandas · NumPy · NVIDIA Nemotron · Nebius Token Factory
